# Juego nuevo de Roblox

Proyecto de un juego de Roblox construido con Rojo: el código vive en este repo y se sincroniza a Roblox Studio.

Reglas de trabajo, para humanos e IAs: ver [`AGENTS.md`](AGENTS.md). Estado actual: [`docs/ESTADO.md`](docs/ESTADO.md).

## Cómo arrancar

1. Instala Rojo (por ejemplo con Rokit) y el plugin de Rojo en Roblox Studio.
2. En la raíz del repo, corre `rojo serve default.project.json`.
3. En Studio, abre el lugar de pruebas y conéctalo con el plugin de Rojo.

Los cambios en `src/` se ven en Studio al instante. No edites scripts dentro de Studio.
