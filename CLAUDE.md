# Claude Code

Sigue exactamente las reglas de `AGENTS.md` (están en la raíz de este repo). Léelo completo antes de empezar.

Resumen rápido:
- Al empezar: `git pull origin main`, crea o usa tu rama de fase, lee `docs/ESTADO.md`, las últimas entradas de `docs/BITACORA.md` y `docs/DECISIONES.md`.
- Trabajo y pruebas solo en el lugar de pruebas de Studio, sin copias (ver AGENTS.md).
- Al terminar: entrada en `docs/BITACORA.md`, actualiza `docs/ESTADO.md`, commit con prefijo `[claude]`, push y Pull Request a `main`.
